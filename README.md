#🐢 ChiquiOS

Un pequeño sistema operativo con un gran sueño.

ChiquiOS es un sistema operativo basado en Alpine Linux, creado con curiosidad, imaginación y muchas ganas de aprender.

📖 La historia de ChiquiOS

Todo comenzó cuando un niño de 10 años tuvo una idea: ¿y si pudiera crear su propio sistema operativo?

No quería simplemente usar lo que ya existía. Quería aprender cómo funcionaba Linux, experimentar con sus componentes y construir algo propio, con su identidad y sus propias herramientas.

Así nació ChiquiOS.

En este proyecto hay algo muy especial: su propio gestor de paquetes, Bacus-Pkg, cuyo nombre está inspirado en Baco, la tortuga que acompaña al creador de esta aventura.

Y, por supuesto, Baco tiene una misión importante: ¡proteger ChiquiOS! 🐢

En el universo de ChiquiOS, Baco es el guardián del sistema. Cuida simbólicamente sus paquetes, acompaña cada nueva compilación y recuerda que incluso los proyectos más pequeños pueden crecer hasta convertirse en algo extraordinario.

ChiquiOS no nació de una gran empresa ni de un enorme equipo de ingenieros. Nació de una idea, de las ganas de aprender y de la ilusión de construir algo propio.

Porque para crear algo grande, primero hay que animarse a imaginarlo.

📦 Bacus-Pkg

Bacus-Pkg es el gestor de paquetes propio del proyecto.

Su código fuente se encuentra en el repositorio público:

➡️ https://github.com/ciberspar/Bacus-pkg

El objetivo es integrarlo directamente en ChiquiOS para que los usuarios puedan gestionar sus herramientas y aplicaciones desde el propio sistema.

Bacus-Pkg continúa en desarrollo, y sus operaciones se están adaptando y probando para que funcionen correctamente sobre Alpine Linux.

💻 Ediciones

ChiquiOS CLI

La edición ligera, pensada para quienes prefieren trabajar desde la terminal.

* Alpine Linux para x86 de 32 bits.
* Herramientas esenciales.
* Terminal y utilidades del sistema.
* Bacus-Pkg integrado.

ChiquiOS Pixel Edition

La edición gráfica, inspirada en el estilo del escritorio PIXEL de Raspberry Pi OS.

* Escritorio ligero basado en componentes como LXDE y Openbox.
* Administrador de archivos y terminal gráfica.
* Personalización visual propia.
* Aplicaciones adicionales.
* Bacus-Pkg integrado.

🛠️ Tecnología

* Base: Alpine Linux.
* Arquitectura inicial: x86 de 32 bits.
* Construcción: GitHub Actions y herramientas oficiales de Alpine.
* Gestor de paquetes: Bacus-Pkg.
* Mascota y guardián simbólico: Baco, la tortuga. 🐢

🚧 Estado del proyecto

ChiquiOS está en desarrollo. Las imágenes generadas deben probarse para verificar el arranque, la compatibilidad del hardware, el escritorio y las funciones de Bacus-Pkg.

El objetivo es construir un sistema ligero, útil y fácil de explorar, que pueda seguir creciendo con nuevas herramientas y mejoras.

Cada compilación es una oportunidad para descubrir algo nuevo.

Y mientras ChiquiOS sigue creciendo, Baco permanece de guardia.
